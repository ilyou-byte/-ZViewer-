# Live Z

基于开源项目 **ZViewer** 修改的非官方版本，感谢ZViewer的开源工作，仅供自用与分享。本项目与上游作者无关。

- 上游项目：https://github.com/Zero-wyc/ZViewer
- 基线版本：上游 v5.1.8（2026-11-05）
- 桌面端版本：0.4.1

## 下载

- `LiveZ-windows-x64-GUI.zip`：Windows x64 便携包，解压即用（首次运行管理员账号 `root` / 密码 `root`）
- `LiveZ-source.zip`：源码包（前端 + Go 后端 + 桌面壳 + 中转服务）

文件与版本说明见 Releases。
